# *Computer Science Trivia*

Submitted by: **Anika Nazhat**

This web app: **This web app is a flashcard-style study tool for computer science trivia, allowing users to flip cards to view answers and test their knowledge on programming, algorithms, tech history, and more. It allows users to enter their guess to an input box before flipping card as well as keep track of the number of correct answers.**
